# 개발 노하우

출처: [evenhub.kr/ai-dev/knowhow](https://evenhub.kr/ai-dev/knowhow) (2026.11.17 수집, 63개 항목 중 공개된 23개). 커뮤니티 개발자가 공개한 이슈·글의 요약이다. 실기기 검증은 원 보고자의 것이고 이븐허브코리아가 다시 시험하지 않았다. 공식 문서와 다르면 공식·최신을 따른다. 나머지 항목은 MCP의 `search_g2_knowledge`로 찾는다([setup.md](setup.md)).

확인 정도: **공식** = 공식 문서·패키지로 뒷받침됨. **여러** = 서로 다른 개발자 2명 이상이 보고. **단일** = 한 개발자·프로젝트의 보고. **미확인** = 추정이거나 관찰이 엇갈림.

각 항목의 원문 링크는 출처 페이지에 있다.

## 먼저 알아야 할 것

| ID | 확인 | 문제 | 해결 |
|---|---|---|---|
| 버전 | 공식 | npm SDK 0.0.16은 최소 Even App 2.2.10을 요구한다. 공식 도구 설치 페이지는 0.0.14·2.2.9, Changelog는 0.0.15·0.0.16 항목이 없다 | 작업 전 `npm view @evenrealities/even_hub_sdk version minAppVersion`. pack에 `--sdk-ver <설치 버전>`. 0.0.15 이상이면 Even App 2.2.10 미만 사용자는 앱을 못 연다 |
| KH-001 | 여러 | 한 번 탭(`CLICK_EVENT`=0)은 `eventType` 키 없이 온다. 탭·더블탭이 `sysEvent`로 오는 경우가 많다 | 정규화 함수 하나로 `textEvent`·`sysEvent`·`listEvent`를 모두 본다. 봉투가 있을 때만 `eventType` 없음을 탭으로 본다. 명시 값(더블탭·스크롤)을 먼저 비교하고 탭은 마지막에 처리한다. 그래야 스크롤·오디오 이벤트가 가짜 탭이 되지 않는다. (어느 봉투로 오는지는 보고마다 다르다) |
| KH-019 | 여러 | `shutDownPageContainer(1)` 종료 창을 한 번 띄우면, 취소해도 `updateImageRawData`가 계속 실패하고 `audioControl(true)`가 false를 준다. 텍스트는 정상. 앱을 다시 열어야 풀린다 | 루트 더블탭의 `shutDownPageContainer(1)`은 심사 규칙이라 유지한다. 이미지·마이크 앱은 루트 더블탭으로 앱 메뉴를 열고 그 안의 종료 항목에서 창을 띄운다(공식 심사 문서의 Chess 예시). 막히면 앱을 다시 열라고 안내한다. (2026-11 공식 이슈 미해결) |
| KH-027 | 여러 | 패키지 설치 앱의 WebView 출처가 실행마다 `http://127.0.0.1:<임의 포트>`로 바뀌어 `localStorage`·IndexedDB가 비었다는 보고 | 중요한 설정은 `bridge.setLocalStorage`에 문자열로 저장하고 시작 때 읽어 메모리에 둔다. 삭제 API가 없으니 빈 문자열을 '없음'으로 본다. Beta 빌드로 재시작 후 유지를 확인하고 첫 실행 안내로 복구할 수 있게 한다. (공식 FAQ는 항상 유지된다고 적음) |
| KH-011 | 여러 | `createStartUpPageContainer` 두 번째 호출은 약 2초 막힌 뒤 1(invalid)을 주고 그동안 입력이 버려진다. Vite HMR 새로고침마다 생긴다 | 호출 사실을 성공 여부와 상관없이 기록하고 이후 변경은 `rebuildPageContainer`로 한다. HMR 뒤 1이 나오면 rebuild로 넘어가거나 시뮬레이터를 다시 띄운다 |
| KH-057 | 공식 | 개발자 약관은 금융, 건강·의료·진단, 교육·훈련, 인스턴트 메시징, 아동 대상 앱을 현재 게시 대상에서 뺀다 | 기획 전에 약관을 읽는다. 민감 정보를 모으지 않고 개인정보처리방침을 준비한다 |
| KH-051 | 공식 | 공식 minimal 템플릿의 `app.json`은 name에 'Even'(사칭 반려), `min_sdk_version` 0.0.10(심사 하한 미만), `package_id` `com.example`이다. `evenhub init` 기본값도 `min_sdk_version` 0.0.7 | `package_id`·`name`을 바꾸고 `min_sdk_version`을 설치한 SDK 버전으로 맞춘다. `min_app_version`은 지우고 pack의 `--sdk-ver`로 계산하게 한다 |
| KH-024 | 공식 | G2는 한국어를 표시한다. 글꼴에 없는 글자는 오류 없이 빠지고 이모지·일부 화살표는 네모로 보였다는 보고. 한글은 UTF-8 3바이트라 바이트 한도에서 훨씬 적게 들어간다 | 이모지를 쓰지 않는다. 기호는 실기기에서 확인 후 쓴다. 한도는 바이트로 보수적으로 잡는다(한글 약 333자, 리스트 항목 약 21자). 정확한 폭은 `@evenrealities/pretext`로 잰다. (글꼴의 한글 범위와 한도 단위는 미확인) |
| KH-035 | 여러 | 플러그인 WebView에서 `getUserMedia`는 NotAllowedError, Android의 `navigator.geolocation`은 막힌다 | 마이크는 `audioControl(true, AudioInputSource.Glasses 또는 Phone)`, 위치는 `getAppLocation`·`startAppLocationUpdates`. `app.json`에 권한을 선언한다 |
